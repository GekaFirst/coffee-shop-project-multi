# ☕ Кофейный рай

Многостраничный сайт-визитка уютной кофейни. Проект создан в рамках обучения вёрстке на HTML и CSS.

## 📄 Страницы

- **Главная** (`index.html`) — приветственный экран с hero-секцией и популярными напитками
- **Меню** (`menu.html`) — каталог напитков с ценами
- **О нас** (`about.html`) — история кофейни
- **Контакты** (`contacts.html`) — адрес, телефон, часы работы

## 🛠 Технологии

- HTML5 — семантическая разметка
- CSS3 — Flexbox, адаптивная вёрстка, медиазапросы
- БЭМ — методология именования классов
- Git — контроль версий

## 🎯 Что я практиковал

- Семантические теги: `<header>`, `<main>`, `<footer>`, `<section>`, `<nav>`
- Мета-теги: `description`, `viewport`, Open Graph
- Адаптивная вёрстка через `@media`
- Навигация между страницами
- Hover-эффекты и переходы
- Структуру проекта: отдельные папки для CSS и изображений

## 🚀 Как запустить

Открой `index.html` в браузере — всё работает без сборки и сервера.
